# The Best Advisory website

## Quick Start
Ask Claude Code in VSCode:
- **"run the site"**: starts the site on your computer and gives you the link to open.
- **"stop the site"**: stops the site running on your computer.
- **"undo my local changes"**: throws away edits that are not published yet.
- **"publish my work"**: checks the code, commits and pushes. The live site updates in a few minutes.

## Install Git & Sign up to GitHub
1. Download Git for Windows/Mac
    - https://git-scm.com/install/windows
    - https://git-scm.com/install/mac
2. Run the installer & keep the default options
3. Open terminal & verify the installation
    - git --version
4. Sign up for GitHub using Google or Apple
    - https://github.com/signup
5. Configure Git identity
    - git config --global user.name "Client Name"
    - git config --global user.email "client@email.com"
6. Authenticate GitHub
    - git push (first time it prompts authentication)
7. Clone repository
    - git clone https://github.com/kahaav/the-best-advisory-website.git
    - cd cd the-best-advisory-website
    - git status

## Install Node.js and npm
1. Download Node.js for Windows/Mac
    - https://nodejs.org/en/download
2. Install Node.js and restart terminal
3. Open terminal & verify the installation
    - node --version
    - npm --version

## Install Visual Studio Code + Claude Code extension
1. Install dependencies inside the project folder
    - npm install
2. Download VSCode for Windows/Mac
    - https://code.visualstudio.com
3. Run the installer and launch the VSCode
4. Open the-best-advisory-website project in VSCode
5. Open Extensions panel and search for 'Claude Code' by Anthropic
6. Click Install
7. Open Claude Code panel in VSCode
8. Follow the authentication prompts

## Install Claude Desktop
1. Download Claude Desktop:
    - https://claude.ai/download
2. Install the application for Windows or Mac.
3. Launch Claude Desktop.
4. Sign in using your Claude account.
5. Make sure your account has access to Claude Code. A paid Claude plan is required for this functionality.
6. Open the Code tab inside Claude Desktop.
7. Select the option to open an existing project or local folder.
8. Navigate to and select: *the-best-advisory-website*
9. Allow Claude Code to access the project folder.
10. Review any permission requests before allowing Claude to edit files or execute terminal commands.
