# State Management

- Prefer local React state by default.
- Use Context for genuinely shared application-level state.
- Introduce external state management only when complexity justifies it.
- Keep state minimal.
- Avoid duplicated state.
- Prefer derived values over storing calculated values.
- Avoid deeply nested state structures.
- Keep server state separate from local UI state.
- Avoid manually duplicating server state across components.
- Choose state management libraries based on actual requirements.
